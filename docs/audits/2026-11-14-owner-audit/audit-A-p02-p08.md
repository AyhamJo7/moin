# Audit A: real status of P02, P05, P06, P07, P08 (main 0e020d2, read-only, 2026-11-13)

Method: plan text via `plan_section.py`; code via `git ls-files` / `git grep` / Read. No test suite was run, CI was not queried, GitHub settings (ruleset, Renovate app) and AWS were not inspected.

Classification rule used: **CANDIDATE** = code + tests exist and a runtime entrypoint (api / voice / worker / web) or a CI job actually exercises it as the item describes. A library that only its own tests import is **PARTIAL** ("DB layer only"), even though those tests run in CI.

## Runtime facts everything below rests on

- **HTTP surface of the whole product** (`git grep @Get/@Post apps/server/src`): `/healthz`, `/readyz`; `api/auth` login, callback, step-up, sign-out-others; `api/members` invite, invitations/:id/revoke, disable, remove, transfer-ownership; `api/recovery` disable-user, enable-user, revoke-sessions; `api/support` grants (create, revoke, list); `api/today`; `api/tasks/:id` and `:id/complete`; `api/dev/simulated-calls` (dev only); `voice/inbound`, `voice/session-end`.
- **`@moin/db` functions with a non-test caller in apps/**: `withTenant`, `appendAuditEvent` (members controller only), `listTodayTasks`, `getTask`, `completeTask`, `captureCallbackRequest` (dev simulator only), `executeJob` (worker), identity store, `verifyAuditChains` (CLI only). Everything else in `packages/db/src` is imported by tests only.
- **Not exported from `packages/db/src/index.ts` and without any caller**: `outbox.ts`, `inbox.ts`, `idempotency.ts`, `timers.ts`, `sse.ts`, `flags.ts`, `job-history.ts`.
- **Voice path persists nothing**: `voice.controller.ts` / `voice.module.ts` import no `@moin/db` write; CallSid dedup is `createInMemoryCallDedup`. A real inbound call creates no call row, outcome or task.
- **Web app** = one page (`apps/web/app/page.tsx`, Heute + Erledigt, 15 s poll). No login page, no other view.
- **Worker** = `JobConsumerModule` with `new JobHandlerRegistry()` empty; nothing publishes to the queue.
- **Infrastructure**: `infrastructure/terraform/**` holds four `.gitkeep` files, 0 `.tf`. Workflows: codeql, container-scan, pr-title, review-annotations, security-scan, verify. No deploy/release workflow.
- **No Valkey, S3, SES, Scheduler, Secrets Manager, Cognito or OpenTelemetry client dependency** in any `package.json` (only `REDIS_URL` as an optional config key).

## Five gaps that block a working end-to-end pilot

1. **A real call leaves no trace.** `voice/inbound` answers with TwiML and a relay session but writes no call, outcome or task; dedup is in memory. The only path that produces a Heute entry is the dev-only simulator. Needs: voice path → `ingestCall` / `captureCallbackRequest` / finaliser (P07.05, P07.11, P11).
2. **Nothing runs in the background.** Empty handler registry, no publisher, no outbox dispatcher, no timers/sweeps, no reconciler schedule. INV-06 (no lost interaction) and every "within 15 min" promise exist only in tests (P08.02, .07; P07.11).
3. **The release image cannot start two of four roles**, and there is nowhere to deploy it: 0 Terraform files, no deploy workflow, no staging (P02.03.02/.07, all of P05; EXT-09, DG-00).
4. **A tenant cannot be onboarded through the product.** `provision_tenant` has no entry point, `db:seed` applies 0 rows, invitations have no accept route and send no email, the web app has no login page, Cognito does not exist (P06.04, P06.08, P06.05; EXT-09).
5. **The business model has no API.** Contacts, leads, appointment requests, notes, search and all task mutations except "complete" are DB functions with tests and no route; the plan has no item that owns those routes. The owner app is one read view plus one button.
