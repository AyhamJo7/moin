## 11. Shortest path to the target demo, locally, with no provider account

Target: a simulated inbound call produces a callback task the owner sees and completes in the web app, with AI
disclosure, a knowledge-backed FAQ answer and a notification.

Two entry points exist. The dev HTTP simulator already reaches the database; the Twilio-shaped voice path
already carries the disclosure and a signed webhook but writes nothing. The shortest honest route keeps the
voice path as the entry (a local script signs requests with a local test auth token, so no Twilio account) and
replaces the measurement script with a small deterministic conversation. No model is needed: FAQ selection by
the existing trigram `findAnswer`, callback intent by the existing `interpretCall`.

| #   | Wiring step                                                                        | Reuses (exists, tested)                                                                                                                                             | New code                                                                                                                                                                        |
